날씨 지역 선택

동 이름 입력 → 좌표 검색 → 검색 결과 선택 → 저장. 검색 결과가 부정확하면 아래의 기존 좌표 직접 입력을 사용하세요.

지역 변경 후 저장하면 LCD 날씨가 새 지역으로 갱신됩니다.

지역은 영문 지명 또는 위도,경도를 권장합니다. WeatherAPI 키는 여기 입력하지 않고 Apps Script의 비공개 스크립트 속성 WEATHERAPI_KEY에 등록합니다.

미리보기 날씨는 저장된 서버 지역 기준입니다. 지역을 변경했다면 저장 후 새로 열어 확인하세요. 실제 날씨는 WeatherAPI 서버에서 약 10분 단위로 자동 갱신합니다. 인터넷 장애 시 이전 조회값에 갱신 시각을 표시합니다.

점검 안내 화면 · 수동 표시

체크하고 저장하면 LCD에서 시계·날씨·문자 대신 점검 안내를 표시합니다. 체크를 해제하고 다시 저장하면 원래 화면으로 돌아갑니다. 인터넷 오류나 응답 지연만으로 자동 전환하지 않습니다.

미리보기만으로 LCD가 변경되지는 않습니다. 실제 반영에는 반드시 「저장 · 반영」을 눌러야 합니다.
