사용 방법

GitHub에 로그인한 상태에서 GitHub에 사진 업로드하기를 누르세요. 사진은 images 폴더에 올리고 001.jpg, 002.jpg처럼 이름을 정하면 순서대로 재생됩니다. 이미지는 GitHub에 반영된 뒤 슬라이드 화면에서 자동으로 갱신됩니다.

이 페이지에는 토큰·비밀번호를 입력하지 않습니다. GitHub 로그인은 GitHub 사이트에서만 진행합니다. GitHub Pages만으로 웹페이지가 저장소에 직접 쓰도록 만드는 것은 불가능합니다.
