슬라이드쇼 관리자

GitHub Pages의 images 폴더를 관리합니다. 공개 화면은 index.html에서 확인하세요.

▶ 슬라이드 보기

1. 저장소 연결

토큰은 이 페이지의 메모리에서만 사용하며 파일이나 브라우저 저장소에 저장하지 않습니다. 공개 PC에서는 사용하지 마세요. 저장소 한 개만 선택하고 Contents 권한만 부여한 단기 토큰을 권장합니다. 이 페이지 자체는 공개되므로 토큰을 HTML 코드에 절대 입력하지 마세요.

2. 이미지 업로드

시작 번호를 입력하면 업로드 순서대로 001.jpg처럼 이름을 지정합니다. 기존 파일과 같은 이름이면 덮어쓰므로 확인하세요. 슬라이드 재생 순서는 파일명 오름차순입니다.

3. 현재 이미지 목록

저장소 정보를 입력하고 연결 및 목록 조회를 누르세요.
