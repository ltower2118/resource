실시간 LCD 미리보기 (16:9)

16:9 화면 전체가 잘리지 않고 표시됩니다. 아래 편집 내용과 같은 서식을 사용합니다. 시계 화면

시간

날짜

문자 전체화면 자동 교대

글자 크기 · 색상 · 글꼴 등 상세 편집

입력창과 미리보기는 같은 1700px 기준 문자 폭과 크기 비율을 사용합니다. 위 미리보기와 LCD는 동일한 서식으로 표시됩니다. 개별 px 크기는 LCD 기준이며 입력창에서는 축소하여 보여줍니다.

문자를 선택한 뒤 굵게·밑줄·형광펜을 적용하세요. Enter로 줄바꿈할 수 있습니다.

설정 저장 후 LCD에서 시계 → 문자 → 시계를 자동 반복합니다. 문자 기능을 끄면 기존 시계만 계속 표시합니다.
