배경

배경 이미지는 GitHub의 ds/images 폴더에서 교체합니다. 같은 파일명으로 변경해도 LCD가 주기적으로 새로 읽습니다.

문자 전체화면 자동 교대

입력창은 LCD와 같은 배경·색상·글꼴·정렬·상대 글자 크기로 표시합니다. 선택 글자 크기 150%는 LCD에서도 기본 크기의 150%입니다.

문자를 선택한 뒤 굵게·밑줄·형광펜을 적용하세요. Enter로 줄바꿈할 수 있습니다.

설정 저장 후 LCD에서 시계 → 문자 → 시계를 자동 반복합니다. 문자 기능을 끄면 기존 시계만 계속 표시합니다.
