출구에서 미인식으로 뜨는경우

1. 출차중 인식이 안되는경우
-> 모니터 터치-> 차량번호 4자리 입력
-> 금액이 뜨면 결재
-> 출차

2. 입차확인이 된경우 ->
금액 0 차단기 올라감.

3. 안열릴경우 후진후 재진입

4. 결제안됨 미확인차량인경우
-> 원할한 주차유도를 위해 후진후 처리 현금받기,계좌이체
-> 차량번호및 출차시간메모
